# 相談内容

AI に強い人と話して2つの感覚を持ち帰った。

1. Claude Code や Codex をいじるのは how でしかなく、why が大事。why に向かうと LLM そのものを知る必要がある。だからハーネス設計に LLM のエッセンスを入れる必要がある。
2. 必死にハーネスを考えているが、AI 時代においてはまだ浅瀬にいる。海はもっと広い。

# 検討・調査

## 「LLMを知る」は3層に割れる

知る対象を「ハーネス設計の判断を変えるか」で切ると3層になる。

- **層1: LLM一般の構造的事実**。アーキテクチャと訓練方法から必然的に出る性質で、世代交代しても変わらない。これがエッセンス。
- **層2: モデル世代固有の癖**。観測で取り、世代ごとに捨てる。[gpt-5.6 モデルプロファイル](/tech/gpt-56-model-profile.md) が既にこの層を「次世代が来たら破棄」とラベル付けしている。[モデル移行観測フロー](/tech/model-migration-observation-flow.md) の2層蒸留と同じ区分。
- **層3: 内部機構の詳細**（attention の数式、RLHF の目的関数の導出）。教養としては面白いがハーネス設計の判断をほぼ変えない。ROI の崖はここ。

助言の「LLMを知る必要」は層1を指す。層3まで潜る必要はない。

## 層1はすでに断片的に所有している — 欠けているのは因果の向き

既存 knowledge のハーネス側結論の多くは、層1の事実から導ける。ただし現状は「失敗→対策」の向きで散在しており、「LLMの性質→だからこの対策」という配線になっていない。

| LLMの構造的事実（層1） | 導かれるハーネス原則 | 既存文書 |
|---|---|---|
| 出力は分布からの確率的標本 | 1回の成功は証拠にならない。N回×率で測る、検証機構必須 | [eval 入門](/tech/evals-for-practitioners.md) |
| プロンプトは命令ではなく条件付けの証拠 | 文面で戦わずコンテキストを設計する | [プロンプト力の階段](/tech/prompting-mastery-ladder.md) |
| 事前分布は訓練データ由来で偏る | 参照例・反例で分布を移動。放置すると縮退解 | [業務システムUIのプロンプティング](/tech/business-system-ui-prompting.md), [ベーコンの4イドラ](/tech/bacon-idols-as-agent-constraints.md) |
| 呼び出し間に状態なし、コンテキストが唯一の入力 | 境界フィルタ・使い捨てコンテキスト・トークン経済 | [ハーネスのトークン経済学](/tech/harness-token-economy.md) |
| 規則は領域を定義し、例は点を打つ | few-shot の機能的使い分け | [例の螺旋](/tech/prompt-examples-spiral.md) |
| 従わない確率が常に残る | 知識層と強制点の分離、保証は機械に持たせる | [強制点の設計](/tech/skill-to-harness-enforcement.md) |

よって「ハーネスに LLM のエッセンスを入れる」は新知識の獲得ではなく、**散在する結論を層1起点の因果配線に束ね直す作業**。効用は、新しい失敗に出会う前に対策を演繹できるようになること。

## 理論と観測ループの関係

「why は LLM 理解からしか来ない」は言い過ぎ。失敗観測駆動ループは理論なしで why に到達する別経路であり、現に到達してきた。層1理論の価値は [仮説思考の導入](/tech/hypothesis-driven-agent-exploration.md) の言葉で言えば**仮説生成の速度** — 観測だけだと失敗に出会ってから学ぶが、層1を持つと失敗前に「この設計は縮退するはず」と予測できる。理論は観測の代替ではなく、次に買う観測の値付けを速くする装置。

## 「浅瀬にいる」の測定を直す

「浅瀬→深海」の比喩は、1本の深さ軸（LLM理解）の浅い方にハーネスがある、という絵を暗黙に置くが、実際の地形は複数の海:

- **利用の海** — プロンプト・ハーネス・委譲の設計（現在地）
- **評価の海** — eval 設計・判定器・挙動の系統観測
- **育成の海** — ポストトレーニング・RL環境設計・報酬設計（モデルを作る側）
- **解剖の海** — 解釈可能性・アーキテクチャ研究
- **社会実装の海** — 組織設計・マルチエージェント経済・統治

これらは1本の航路でつながった深さの階段ではない。育成の海で深いラボ研究者が利用の海では浅い、は普通にある。**深さは海ごとに測る**。強い人と話して浅瀬感を覚えるのは、相手の最深次元をサンプリングして自分の平均と比べる測定の歪み。

ただし感覚の芯には本物の事実がある: **海が広がる速度は泳ぐ速度より速い**。全員が全体に対しては浅瀬にいるのがこの時代の恒常状態で、差がつくのは「どの海の深さが自分の判断を変えるか」の選択と、観測ループの速さ。

# 結論

1. 知識の価値は「ハーネス設計・委譲の判断を変えるか」で測る。層1（LLM一般の構造的事実）だけがエッセンスで、層2は観測で取って世代ごとに捨て、層3には当面入らない。
2. 次の一手は「層1の事実を10個以内に絞り、各項をハーネス設計レバーに配線した1枚」を作ること。→ 実行済み: [LLM の構造的事実9つとハーネス設計レバーへの配線](/tech/llm-structural-facts-to-harness-levers.md)
3. 海図としての選択: 評価の海への深入りは続行（339ランで実証済み）。育成の海は「海図を読める」水準のリテラシーを取る — 訓練が何を最適化しているかを知ると迎合性・完了圧・縮退解の why が演繹できる。解剖の海は保留。
4. 「浅瀬にいる」感覚の正体は後退ではなく「海が複数あると視認した瞬間の眩暈」。放置すると「全部やらなきゃ」の散漫に化けるため、海図に変換して固定する（本文書がその固定）。ハーネス設計は利用の海の深い方であり、浅い活動ではない。
